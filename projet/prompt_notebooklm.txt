# 5. PSO : principe général

Explique clairement ce qu'est le Particle Swarm Optimization.

Utilise l'analogie d'un groupe d'oiseaux ou d'un essaim :

- chaque particule représente une solution ;
- chaque particule possède une position ;
- chaque particule possède une vitesse ;
- chaque particule mémorise sa meilleure position ;
- l'essaim mémorise la meilleure position globale.

Présente les variables :

```text
x_i : position de la particule i
v_i : vitesse de la particule i
p_i : meilleure position personnelle
g   : meilleure position globale
```

Explique l'équation :

```text
v_i(t+1) =
    ω v_i(t)
    + c1 r1 (p_i - x_i(t))
    + c2 r2 (g - x_i(t))
```

Puis :

```text
x_i(t+1) = x_i(t) + v_i(t+1)
```

Explique chaque terme :

- `ω` : inertie ;
- `c1` : coefficient cognitif ;
- `c2` : coefficient social ;
- `r1` et `r2` : nombres aléatoires ;
- terme cognitif : retour vers la meilleure position personnelle ;
- terme social : attraction vers la meilleure position de l'essaim.

Dans le projet :

```text
c1 = 1.5
c2 = 1.5
```

Explique la variante améliorée :

- diminution linéaire de l'inertie ;

Explique pourquoi cette amélioration est utile :

- à la fin, une inertie plus faible favorise la convergence ;
- la limitation de vitesse évite que les particules quittent trop brutalement

- elle réduit les risques de divergence dans les grandes dimensions.

# 10. Les deux modes de calcul de gBest

Le programme CUDA accepte :

```text
--gbest cpu
--gbest gpu
```

## Mode CPU

Explique le fonctionnement :

1. le GPU met à jour les particules ;
2. le GPU met à jour les meilleurs personnels ;
3. les meilleurs personnels sont copiés du GPU vers le CPU ;
4. le CPU recherche le meilleur global ;
5. le meilleur global est recopié vers le GPU.

Avantages :

- simple à comprendre ;
- facile à vérifier.

Inconvénients :

- transferts CPU/GPU à chaque itération ;
- synchronisations fréquentes ;
- performances potentiellement plus faibles.

## Mode GPU

Explique que :

1. les meilleurs personnels restent sur le GPU ;
2. `reduceGlobalBest()` réalise une réduction parallèle ;
3. le meilleur global est calculé sans transfert intermédiaire.

Avantages :

- moins de transferts ;
- meilleure exploitation du GPU ;
- meilleure scalabilité.

Explique le rôle de la mémoire partagée CUDA dans la réduction.

# 11. DE : principe général

Explique ce qu'est Differential Evolution.

Contrairement à PSO, DE ne manipule pas principalement des vitesses. Il crée
de nouveaux candidats à partir des différences entre plusieurs individus de
la population.

Pour chaque individu cible `x_i` :

1. choisir des individus distincts ;
2. construire un vecteur mutant ;
3. appliquer un croisement avec l'individu cible ;
4. borner le candidat ;
5. évaluer sa fitness ;
6. conserver le meilleur entre le parent et l'essai.

Explique que DE travaille avec :

```text
population courante
vecteur mutant
vecteur essai
sélection gloutonne
```

---

# 12. Les stratégies DE

Explique les trois stratégies du projet.

## 12.1. DE/rand/1

Formule :

```text
v = x_r1 + F(x_r2 - x_r3)
```

Explique :

- `r1`, `r2`, `r3` sont distincts ;
- l'individu cible est exclu ;
- la différence entre deux individus fournit une direction d'exploration ;
- cette stratégie conserve une grande diversité.

Paramètre :

```text
F
```

qui contrôle l'amplitude de la mutation.

## 12.2. DE/best/1

Formule :

```text
v = x_best + F(x_r1 - x_r2)
```

Explique :

- la mutation part du meilleur individu connu ;
- la convergence est souvent plus rapide ;
- le risque de convergence prématurée est plus élevé.

## 12.3. DE/current-to-best/1

Formule :

```text
v =
    x_i
    + F(x_best - x_i)
    + F(x_r1 - x_r2)
```

Explique :

- l'individu est attiré vers le meilleur ;
- une différence aléatoire conserve de l'exploration ;
- le comportement est intermédiaire entre exploitation et exploration.

# 13. Paramètres DE

Explique les paramètres :

## Facteur de mutation `F`

Dans le projet :

```text
0 <= F <= 2
valeur par défaut : F = 0.5
```

Interprétation :

- petit `F` : modifications faibles, recherche locale ;
- grand `F` : déplacements plus importants, exploration ;
- valeur trop élevée : mouvements instables ou candidats souvent hors domaine.

## Taux de croisement `CR`

Dans le projet :

```text
0 <= CR <= 1
valeur par défaut : CR = 0.9
```

Interprétation :

- `CR` faible : le vecteur essai ressemble davantage au parent ;
- `CR` élevé : davantage de coordonnées mutées sont utilisées ;
- une coordonnée est toujours forcée à provenir du mutant.

## Population

La population doit contenir au moins quatre individus car DE doit choisir :

```text
individu cible
r1
r2
r3
```

Tous les indices de mutation doivent être distincts.
